В отличие от [[Flex]] позволяет работать сразу в двух измерениях (и горизонтальном, и вертикальном одновременно).

Основные свойства:
1. `grid-template-rows` / `grid-template-columns`
2. `repeat(4, 50px)`, `repeat(auto-fill, 50px)`, `repeat(auto-fit, 50px)`
3. `auto-fill` - когда колонки заканчиваются, а пространство остается, то создает пустые колонки и равномерно распределяет размер между реальными и "виртуальными" колонками
4. `auto-fit` -- почти так-же, как и `auto-fill`, но схлопывает пустые колонки и отдает больше места под заполненные
5. `grid-auto-rows`/ `grid-auto-columns` -- если строк / колонок больше, чем мы можем указать в `grid-template-rows` / `grid-template-columns`, тогда у этих явно не указанных элементов будут размеры из этих свойств
6. `grid-template-areas` -- можно нарисовать макет с помощью названия мест (может быть когда нибудь пригодится). (неплохо себя покажет для адаптивности в сложных макетах)
7. `justify-content` -- выравнивает ячейки внутри grid-контейнера. Задается для контейнера
8. `justify-items` / `align-items` -- выравнивет контент внутри ячеек. Задается для контейнера
9. `justify-self` / `align-self` -- выравнивает контент внутри ячейки. Задается для ячейки
10. `grid-column` / `grid-row` -- позволяет объеденить несколько ячеек.
