## Получение данных с сервера:
```ts
public loadDashboardInfo(): void {  
  this.dashboardApiService.fetchDashboardInfo().pipe(  
    tap((dashboardInfo: DashboardInfo) => this.setDashboardInfo(dashboardInfo)), 
    catchError(error => {  
      this.errorHandlingService.handleError(error);  
      return EMPTY;  
    })  
  ).subscribe();  
}
```
Это хороший вариант, потому что здесь:
1. нейминг соответствует тому, что делает метод;
2. не происходит ничего лишнего (того, что подразумевает метод).
3. легко модифицировать (например добавить retry при неудачном запросе)
