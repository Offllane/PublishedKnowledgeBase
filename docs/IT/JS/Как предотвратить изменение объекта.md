## С помощью дескрипторов
- `enumerable` - отвечает за то, будет ли свойство перечисляться в циакад (for...in, Objecct.keys())
- `writable` - отвечает за то, можно ли изменять свойство
- `configurable` - отвечает за то, можно ли изменять другие дескрипторы свойства, удалять свойство, изменять тип свойства

```js
const obj = {};
Object.defineProperty(obj, 'name', {
	value: 'John',
	writable: false,
	enumarable: true,
	configurable: false
});

obj.name = 'Egor'; // Выдаст ошибку в strict mode
```

## Object.preventExtensions()
Предотвращает добавление новых свойств в объект. Тем не менее, существующие свойства можно изменять и удалять.

## Object.seal()
Не позволяет добавлять новые свойства или удалять существующие. Но позволяет изменять существующие свойства, если они не являются неперезаписываемыми.

## Object.freeze()
Полностью замораживает объект. Нельзя добавлять, удалять или изменять свойства объекта
